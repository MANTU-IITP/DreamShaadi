## 🎨 Color Palette

### Primary Colors

- **Burgundy**: `#762b3f` - Primary brand color, CTAs, headings
- **Gold**: `#d7b16d` - Accents, premium badges, highlights
- **Ivory**: `#fdf6ec` - Background sections, soft contrast

### Neutral Colors

- **Dark**: `#1a1a2e` - Body text, headings
- **Gray**: `#7a7a7a` - Secondary text, descriptions
- **Border**: `#e8ddd0` - Dividers, card borders
- **White**: `#ffffff` - Card backgrounds, overlays

---

## 📝 Typography

### Headings

```css
font-family: "Playfair Display", serif;
font-weight: 700;
```

**Sizes:**

- Hero: `clamp(3rem, 8vw, 6.5rem)`
- Section H2: `clamp(2.5rem, 5vw, 4rem)`
- Card H3: `1.5rem`

### Body Text

```css
font-family: "DM Sans", sans-serif;
font-weight: 400-600;
```

**Sizes:**

- Hero subtitle: `clamp(1rem, 2vw, 1.25rem)`
- Body: `1rem - 1.1rem`
- Small: `0.85rem - 0.9rem`
- Tiny: `0.7rem - 0.75rem`

### Eyebrows (Section Labels)

```css
font-size: 0.75rem;
font-weight: 600;
letter-spacing: 0.15em;
text-transform: uppercase;
color: #762b3f or #d7b16d;
```

## 🎯 Interactive Elements

### Buttons

**Primary CTA:**

```css
background: #762b3f;
color: #ffffff;
border-radius: 100px;
padding: 1rem 2rem;
box-shadow: 0 8px 30px rgba(118, 43, 63, 0.25);
```

**Hover:**

```css
background: #5d071a;
transform: translateY(-2px);
box-shadow: 0 12px 40px rgba(118, 43, 63, 0.35);
```

### Cards

**Default:**

```css
border-radius: 16px;
box-shadow: 0 4px 20px rgba(0, 0, 0, 0.08);
transition: all 0.4s cubic-bezier(0.4, 0, 0.2, 1);
```

**Hover:**

```css
transform: translateY(-8px);
box-shadow: 0 12px 40px rgba(0, 0, 0, 0.15);
```

## 📱 Responsive Breakpoints

```css
/* Desktop: Default styles */
/* Large screens: 1200px+ */

/* Tablet: max-width: 992px */
- 2-column category grid
- 2-column destination grid
- Stacked vendor CTA

/* Mobile Large: max-width: 768px */
- 1-column category grid
- 1-column all grids
- Simplified hero

/* Mobile Small: max-width: 480px */
- Reduced padding
- Smaller typography
- Single column everything
```

## ✨ Animation & Effects

### Hover Transitions

- **Duration**: `0.3s - 0.6s`
- **Easing**: `cubic-bezier(0.4, 0, 0.2, 1)` or `ease`
- **Properties**: `transform`, `box-shadow`, `opacity`, `color`

### Image Zoom

```css
transform: scale(1.08);
transition: transform 0.6s ease;
```

### Float Animation (Hero Scroll)

```css
@keyframes float {
  0%,
  100% {
    transform: translateY(0);
  }
  50% {
    transform: translateY(10px);
  }
}
animation: float 3s ease-in-out infinite;
```
